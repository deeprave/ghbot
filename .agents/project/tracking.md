# Project Tracking

GitHub Issues is the active requirements tracker for this repository:

- **Repository:** `deeprave/ghbot`
- **Connector:** GitHub
- **Identifier:** GitHub issue number, written as `#<number>` (for example, `#38`)
- **Canonical link:** `https://github.com/deeprave/ghbot/issues/<number>`

Issues may be imported into local specs, and their descriptions and discussion are the source of
product requirements. Specs remain local planning artifacts: do not create GitHub issues for specs,
nor derive branch names or pull-request titles from issue identifiers.

When a pull request implements an issue, include `Closes #<number>` in its description. Do not
modify GitHub issues unless the user explicitly requests that change.
